# 卡片盒 / Zettel Card Box

卢曼式卡片笔记，为思源而做。

## 这个插件解决什么

大多数人把书读完就结束了：划线存进笔记，然后永远不再打开。问题不在"存"，在于**存下来的都是别人的话**——它们躺在某本书的文档里，写东西时想不起来，也连不成体系。

卡片盒只做一件事：**把一条值得留下的判断，变成一张能独立存在的卡。**

- 卡片的标题是一句你自己的判断，不是名词
- 建卡自动锚定来源：摘抄在上，你的判断在下
- 新卡建进网络：建卡时勾选它接在哪几张卡上，插件也会推荐候选
- 长期没被任何卡引用的会被标成**孤岛**——卡片笔记失败的唯一标志

微信读书的划线与想法在这里是**素材库**：同步进来，挑值得成卡的写成卡，其余留着随时检索。素材是原料，卡片是产出。

## 四种卡

| 类型 | 从哪开始 | 长什么样 |
|------|----------|----------|
| 📖 文献卡 | 攥着一句**别人的话** | 原文摘抄 + 出处 + 你的判断 |
| 💡 想法卡 | 攥着**你自己的念头** | 判断 + 它接在哪几张卡上 |
| 🌏 地图卡 | 攥着**一个地方** | 知识钉在世界地图上（海峡/港口/航线…） |
| 📜 永久卡 | 攥着**几张卡** | 按顺序合成一篇文章，嵌入块联动更新 |

一个「＋ 新建」入口，四种起点。微信读书想法成卡时，你的评论自动预填「我的判断」——写下评论的那一刻它就是判断。

## 卡片工作台

- **筛选**：全部 / 文献 / 想法 / 地图 / 孤岛
- **面板内阅读**：点卡片或文档，全文在面板里渲染，不用跳页签
- **🔗 链路图**：SVG 关系图，一眼看清每张卡从哪里长出来、又长出了什么；支持「✍ 由此想」从任意卡长出新想法
- **关联建议**：按标题相关度把候选卡摆出来，勾选即写入块引用
- **删除**：红色按钮 + 二次确认，删后列表立即刷新

## 素材 · 两个来源

**微信读书**
- 通过**微信读书官方 Agent API**（`wrk-` Key）读取，比 Cookie 方式稳定
- 每本书一篇思源文档：按章节分组的划线与想法，块级可检索
- 书架面板：**点开一本书就地展开划线与想法**，勾选多条批量成卡，已成卡的自动标记
- 「未成卡想法」视图：全库还没成卡的想法集中列出，逐条「写成卡」
- 定时自动同步；每条划线块 ID 稳定，重复同步安全

**思源文档**
- 文件树浏览全部笔记本（插件目录自动隐藏）
- 点开文档面板内渲染阅读；**「✍ 整理成卡」块选择器**：勾选多个段落/引用/标题块，一次批量生成文献卡，可统一连到某张已有卡

## 地图卡与总览

读书时会遇到和地方绑定的知识（例：拉腊克岛卡在霍尔木兹海峡入口）。地图卡把这类知识钉在离线世界地图上——选点、框选区域、悬停报经纬度；「🌏 地图」总览把所有卡钉在同一张图上，同位置的聚成一钉。

## 块属性（同步内容）

| 属性 | 挂在哪 | 用途 |
|------|--------|------|
| `name`（块命名） | 划线 / 想法 | 反链与 `((引用))` 处显示划线正文 |
| `custom-weread-book` | 所有同步块 | bookId，按书聚合查询 |
| `custom-weread-type` | 所有同步块 | `highlight` / `thought` / `chapter` / `meta` / `cover` |
| `custom-weread-chapter` | 划线 / 章节 | 所属章节名 |
| `custom-card-type` | 卡片文档 | `文献` / `想法` / `永久` / `地图` |
| `custom-card-source` | 文献卡 | 锚定的来源块 ID |
| `custom-card-map` | 地图卡 | 位置 JSON（点 + 区域） |

示例：查某本书的全部划线

```sql
SELECT markdown FROM blocks
WHERE ial LIKE '%custom-weread-book="23444346"%'
  AND ial LIKE '%custom-weread-type="highlight"%'
```

## 获取微信读书 API Key

1. 打开 [weread.qq.com/r/weread-skills](https://weread.qq.com/r/weread-skills)（或在微信读书 App → 设置 → 微信读书 Skill）
2. 微信扫码登录，点击「获取 API Key」，复制 `wrk-` 开头的 Key
3. 粘贴到本插件设置面板，点「校验」确认

> Key 绑定你的微信读书账号，仅保存在本地思源插件数据目录，不会上传到任何第三方。

## 使用

1. 设置面板选择目标笔记本与文档根路径
2. 打开侧边栏「卡片盒」面板：素材里挑内容成卡，卡片页整理与回顾
3. 重复同步是安全的：已有划线原地更新（块 ID 不变），新划线按位置插入

## 提示

- 永久卡里的卡片是**嵌入块**：源卡改动，文章里的内容跟着变
- 「全量重建」会删除并重建所有微信读书文档，**已有块引用会失效**，慎用
- 微信读书接口仅能导出划线与想法；书签只有数量（官方限制）
