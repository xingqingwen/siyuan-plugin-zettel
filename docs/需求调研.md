# 需求调研报告 — 思源微信读书同步插件 v0.2

> 调研时间：2026-10-22。证据来源：Obsidian 同类插件（zhaohongxuan/obsidian-weread-plugin v2）、weread2notion-pro、微信读书工具箱（sancijun）、各项目 README/更新日志中记录的用户反馈、官方 Agent API 实测（17 个接口全量清单）。

## 一、用户真实痛点（按出现频率与强度排序）

| # | 痛点 | 证据来源 | 本插件现状 |
|---|------|---------|-----------|
| 1 | **覆盖式更新毁掉用户手工添加的笔记**——weread2notion-pro 明文警告"不要在 Page 里添加自己的笔记"，Obsidian 旧版 README 同样警告 | 两个项目 README | ✅ 已解决（块 ID 保留 + 原地更新），这是**核心卖点** |

| 3 | **首次同步慢**（上百本书），后续更新也慢 | Obsidian v2 为此做了三层优化（并发 5 章、缓存 7 天 TTL） | ⚠️ 未优化，串行逐本请求 |
| 4 | **模板自定义需求强烈**（格式、字段、文件名） | Obsidian 插件功能列表被提及最多 | ❌ 无（固定格式） |

| 6 | **Daily Notes 集成**（当日划线插入日记） | Obsidian 0.4.0 专门为此发版 | ❌ 无 |
| 7 | 最小划线数量过滤、文件名格式、书名重复冲突 | 竞品设置项 + TODO 列表 | ❌ 无 |
| 8 | **阅读统计可视化**（年/月时长、热力图、偏好） | Obsidian v2 主打 | ❌ 无（API：/readdata/detail） |
| 9 | 书籍详情浏览页（封面/评分/进度/四 Tab） | Obsidian v2 主打 | ❌ 无 |
| 10 | 公众号文章划线同步 | Obsidian/工具箱均有 | ⚠️ 官方 API 不覆盖，需 Cookie 通道，暂不承诺 |

## 二、官方 API 能力清单（2026-10-22 实测）

个人内容：划线 `/book/bookmarklist`、个人想法 `/review/list/mine`、单条想法详情 `/review/single`、划线下想法 `/book/readreviews`
社区内容：热门划线 `/book/bestbookmarks`（含人数）、划线热度 `/book/underlines`、公开点评 `/review/list`
元数据：书籍信息 `/book/info`、章节目录 `/book/chapterinfo`、阅读进度 `/book/getprogress`
全书：书架 `/shelf/sync`（含听书）、笔记本概览 `/user/notebooks`（游标分页）
统计：`/readdata/detail`（周/月/年/总，时长、天数、排行、偏好）
发现：个性化推荐 `/book/recommend`、相似书 `/book/similar`、朋友在读 `/discover/interact/type3`
搜索：`/store/search`（书/作者/书单/公众号/全文）

## 三、思源生态的差异化机会（Obsidian 插件照搬不了的部分）

1. **块引用/双链**：划线块 ID 稳定后，用户可以把任意划线引用到读书卡片、日记里批注——这是思源的杀手锏，Obsidian 做块引用体验差。文档要教。
2. **思源没有阅读统计类插件**，统计报告生成思源文档（表格+清单）是空白。
3. **书架 Dock 侧边栏面板**（思源的原生 Dock 机制）：搜索、排序、显示笔记数与上次同步时间、点书跳文档/跳 App。
4. **日记集成**：思源原生日记机制，同步今日新增划线。

## 四、性能设计约束（339 本书 / 3414 条笔记实测数据）

- 全量首同步 = 每本书 2 次网关请求 + 约 10 次内核写请求，必须做：并发上限、**跳过无变化的书**（book.sort=最近笔记时间，≤上次同步时间直接跳过，后续同步近秒级）、断点续传（state 记录）、同步进度条。

## 五、功能分级提案

**P0 上架必备（补齐竞品标配 + 巩固核心卖点）**
1. 同步性能：并发批量、无变化跳过、断点续传、进度反馈
2. 热门划线同步：开关 + 合并/分离两种模式 + 🔥共读人数标注
3. 书籍文档增强：封面、作者/出版社/评分/进度元信息
4. 同步范围控制：最小划线数过滤、只同步"在读/读完"、书名冲突处理（书名+作者命名）
5. 设置里 API Key 有效性校验按钮

**P1 体验增强（上架后第一个版本迭代）**
6. 定时自动同步（间隔可配）
7. 书架 Dock 侧边栏面板
8. 阅读统计报告文档（周/月/年，时长/天数/偏好/榜单）

**P2 远期探索**
9. Daily Note 日记集成
10. 简易模板（占位符级，不做 Nunjucks）
11. 双链工作流文档 + 示例模板（教用户把划线引用到卡片）
12. 发现页（推荐/朋友在读）——价值存疑，默认不做
13. 公众号划线——依赖 Cookie 通道，与差异化路线冲突，不承诺
